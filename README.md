# Lumen Business — Homepage

Static homepage concept for Lumen Business (lumenbusiness.co.nz). Plain HTML + CSS, no build step.

## Structure

```
index.html            Homepage
assets/css/style.css  Styles
assets/img/           Logo, favicon and photos
.nojekyll             Lets GitHub Pages serve the site as-is
```

## Run locally

Open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

## Notes

- Fonts load from Google Fonts (Manrope).
- Stock photos need a valid licence before the site goes live.
